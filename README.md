# Walmart Sales Analysis Dashboard

## Project Overview

This project analyzes Walmart sales data using Power BI to identify sales trends, profit performance, and regional insights. The dashboard helps visualize business performance and supports better decision-making.

## Tools Used

* Power BI Desktop
* Power Query
* DAX
* Excel Dataset

## Key Features

* Sales performance analysis
* Profit analysis by category
* Regional sales comparison
* Monthly sales trend visualization
* Interactive filters and slicers

## Files in this Repository

* AICTE Microsoft elevate project.pbix – Power BI dashboard
* MS Elevate AICTE Internship - Project template.pptx – Project presentation
